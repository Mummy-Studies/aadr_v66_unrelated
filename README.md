# Ancient Human Genomics — AADR v66 HO Compatibility Dataset

This repository contains R code for processing and filtering ancient human genomic
samples from the **Allen Ancient DNA Resource (AADR) v66** using the
`aadr_v66_HOCompatibility` dataset.

The workflow is designed to obtain a high-quality set of ancient human individuals
with sufficient SNP coverage and to identify a set of genetically unrelated
individuals based on the family relationships reported in the AADR dataset.

The resulting individuals can subsequently be restricted to selected geographical
or political entities for downstream population-genomic analyses.

---

## Dataset

The starting dataset is available at:
[The Allen Ancient DNA Resource (AADR): A curated compendium of ancient human genomes](https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/FFIDCW)
